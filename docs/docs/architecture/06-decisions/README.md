# Architecture Decision Records

This directory holds ADRs - short immutable documents each recording one
significant decision, its context, and its consequences. ADRs are superseded,
never edited (glossary definition; produced by accepted RFCs per the
[RFC process](../../community/rfc-process.md) section 2.5).

## Format

`NNNN-short-title.md`, numbered in acceptance order:

```markdown
# ADR NNNN - Title

- Status: Accepted | Superseded by ADR-MMMM
- Date: YYYY-MM-DD
- Source RFC: rfcs/NNNN-short-title.md

## Context
## Decision
## Consequences
```
