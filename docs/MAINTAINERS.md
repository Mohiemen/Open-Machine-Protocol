## Conduct Contacts

Reports under the [Code of Conduct](docs/community/code-of-conduct.md) go to
the contacts below. Per the CoC, conduct enforcement is kept separate from
technical decision-making where the project's size allows; during bootstrap the
project is too small for that separation, which is noted here honestly - a
report concerning the sole maintainer cannot yet be independently handled, and
appointing an independent conduct contact is a tracked bootstrap task.

| Contact | Channel |
|---|---|
| M A Mohiemen Tanim | GitHub private message to [@Mohiemen](https://github.com/Mohiemen), or the email published on the maintainer's GitHub profile |

## Security Contacts

Vulnerability reports follow [SECURITY.md](SECURITY.md) - GitHub private
vulnerability reporting on this repository is the preferred channel and reaches
the core maintainers.
